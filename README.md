# DocuMind — Chat with your PDFs

Upload a PDF, ask questions. It answers from your doc, not from thin air.

What it does:
- PDF upload + chunking
- Semantic search (RAG)
- Streaming answers with sources

Stack: Next.js, Express, MongoDB, OpenAI embeddings + GPT-4o-mini

Run it:
```bash
docker compose up --build
# frontend :3000, backend :8000
```
